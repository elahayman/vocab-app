# עיר המילים

אפליקציית אינטרנט (PWA) לתרגול יומי של אוצר מילים באנגלית, לשני אחים.

## קבצים
- `index.html`, `styles.css`, `app.js`: האפליקציה עצמה. אין שלב build.
- `store.js`: שכבת השמירה. כרגע ב-localStorage של המכשיר; כאן יתחבר Firebase.
- `words.js`: נוצר אוטומטית ממאגר המילים. לא לערוך ידנית.
- `data-src/`: משפטי הדוגמה (`sentences*.txt`, שורה לכל מילה: `id|sentence with ___`) והסקריפט `build_words.py`.
- `sw.js`, `manifest.webmanifest`, `icon*`: התקנה למסך הבית ועבודה בלי אינטרנט.

## עדכון מאגר המילים
```
python3 data-src/build_words.py /mnt/project-files/word-bank/מאגר_מילים_אנגלית.xlsx
```

## הרצה מקומית
```
python3 -m http.server 8000
```
ואז לפתוח את http://localhost:8000

## איך זה עובד
- מפגש יומי: עד 3 מילים מוכרות לחימום, 5 עד 6 מילים חדשות, ובדיקה של כ-12 שאלות.
- סוגי שאלות: פירוש (אנגלית לעברית), השלמת משפט, ואנגלית מעברית (ברמות גבוהות).
- טעות: המילה חוזרת שוב בסוף המפגש, וחוזרת לרמה 1.
- רמות ומרווחים: 1 יום, 3, 7, 14, 30, ואז "נרכשה" (בדיקה חוזרת אחרי 90 יום). מילה נרכשת רק אחרי שזוהתה נכון גם בשאלת פירוש וגם בהשלמת משפט.
- יותר מ-15 מילים לחזרה: חצי מהמילים החדשות. יותר מ-30: בלי מילים חדשות.
- רצף ימים, מגן רצף כל 7 ימים (עד 2), תיבת הפתעה בסוף כל מפגש עם פריט לאי המשותף, בונוס כשהאחים משחקים באותו יום, ויעד שבועי משותף של 10 מפגשים.
- מסך הורים (מאחורי שאלת כפל): התקדמות, מילים עקשניות, והגדרות.
- משפחות מילים: `data-src/morphology.py` (תחיליות וסיומות, נבדקו ידנית). מוצגות בכרטיס הלמידה ובמשוב.
- אתגר כתיב רשות בסוף המשימה: 2 מילים מוכרות (רמה 3 ומעלה), מעברית לאנגלית, שגיאת אות אחת מתקבלת במילים של 5 אותיות ומעלה.

## Blue Pup (`little/`): אפליקציה לבת הקטנה
אפליקציה נפרדת לגיל 4, בלי קריאה: תמונה, הקראה באנגלית, ובדיקה "Where is the cat?" מבין 3 תמונות. כתובת: `.../vocab-app/little/`.
- הכול בקובץ אחד, `little/index.html` (בין ההערות `ARTIFACT-START` ו-`ARTIFACT-END` נמצא מה שמתפרסם גם כתצוגה מקדימה ב-Claude).
- 15 קטגוריות לבחירה שלה. סבב: עד 4 מילים ללימוד, 8 שאלות, שלב "What is this?" שבו היא אומרת מילה מוכרת (בלי ציון), מסיבת בלונים, ובסוף פרס מתחלף: קינוח (גלידה, עוגה או קאפקייק בטעמים שהיא בוחרת), פאזל של 4 חלקים, או דף צביעה של הקטגוריה.
- גדול/קטן, למעלה/למטה, בתוך/על/מתחת מתורגלים בתוך הקטגוריות על מילה מוכרת. כל זוג נפתח כשהקודם ידוע.
- מילה ידועה: 3 תשובות נכונות בניסיון ראשון (טעות מורידה רמה אחת).
- אזור הורים: לחיצה ארוכה על גלגל השיניים. התקדמות, מהירות הקראה, הקלטות של ההורים (מילים, שאלות וחיזוקים, נשמרות ב-IndexedDB) וסנכרון.
- סנכרון בין הטלפונים דרך אותו פרויקט Firebase ואותו קוד משפחה של עיר המילים: `families/{code}/data/little` להתקדמות, ו-`families/{code}/data/clip~{key}` לכל הקלטה. חוקי Firestore הקיימים מכסים את זה.
